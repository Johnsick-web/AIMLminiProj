PROJECT DOCUMENTATION

Mini-project methodology

CO1–CO5 evidence
01

Problem definition

Estimate a student's final mathematics grade (G3 out of 20) early enough to support timely academic intervention. This is a decision-support estimate, not a guaranteed result.

02

Dataset collection

The local student-mat.csv file contains 395 mathematics student records with demographic, school, attendance, study-time, period-grade, and final-grade attributes.

03

Data preprocessing

Only studytime, absences, G1, and G2 are used as model features. These columns and G3 are converted to numeric values; incomplete rows are removed before the reproducible 80:20 split.

04

Model development

The system loads the saved Random Forest regressor and compares it with Linear Regression, Gradient Boosting, and Decision Tree regressors.

05

Performance evaluation

MAE, MSE, RMSE, and R² are calculated on the held-out test set. The dashboard also visualizes grade distribution, study time, and actual versus predicted grades.

06

Model optimization

GridSearchCV evaluates Random Forest hyperparameters with five-fold cross-validation on training data only, selecting the configuration with the lowest validation MAE.

07

Result analysis

Use the metric table to compare errors, the charts to inspect patterns, and the prediction panel to translate an estimate into an actionable support recommendation.

08

Documentation

README.txt records setup, data fields, workflow, evaluation protocol, limitations, and reproducibility steps. The dashboard exposes the same evidence during a demonstration.
